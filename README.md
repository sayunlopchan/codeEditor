# CodePlay - Online Code Editor

![CodePlay Banner](https://via.placeholder.com/1200x400?text=CodePlay+Online+Editor) <!-- Replace with actual screenshot -->

A JS Bin clone created as a capstone project for Mindrisers Institute of Technology's MERN Stack Development course. Built with React, Tailwind CSS, and Monaco Editor to demonstrate comprehensive frontend development skills.

🔗 **Live Demo:** [https://code-editor-mocha-six.vercel.app/](https://code-editor-mocha-six.vercel.app/)

🎓 **Educational Institution:** [Mindrisers Institute of Technology](https://mindrisers.com.np)  
📅 **Course Duration:** 3 Months Intensive MERN Stack Program  

## 🚀 Project Overview

This project was developed as the final assignment for Mindrisers' MERN stack course, showcasing proficiency in modern frontend technologies. The application replicates core JS Bin functionality with enhanced features.

### Key Implementations:
- **Multi-language Editor**:
  - Monaco Editor integration for HTML, CSS, JavaScript
  - Syntax highlighting and intelligent code completion
  - Panel resizing and layout customization

- **Live Rendering**:
  - Real-time code execution preview
  - Error detection and display
  - Responsive output visualization

- **Course Concepts Applied**:
  - Advanced React state management
  - Tailwind CSS utility-first styling
  - Component-based architecture
  - Performance optimization techniques
